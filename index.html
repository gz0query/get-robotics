PROJECT 06

Smart Waste Bin

  • Ultrasonic HC-SR04
  • Servo Motor
  • Arduino / ESP32

An automated hands-free smart trash bin powered by an ultrasonic sensor and a servo motor. When a person's hand approaches within range, the ultrasonic sensor detects the distance and signals the servo motor to automatically open the bin lid, then closes it after a delay.

PROJECT 07

Ultrasonic Alarm Code

  • Ultrasonic HC-SR04
  • Piezo Buzzer
  • Arduino / ESP32

An ultrasonic proximity security alarm using an HC-SR04 sensor, piezo buzzer, and warning LED. When an object or intruder enters the detection zone, the alarm triggers a rapid alert tone and flashes the indicator LED.

PROJECT 08

Keypad Smart Lock (Tinkercad)

  • 4x4 Keypad
  • Servo Lock
  • Arduino / ESP32

A digital PIN security lock built for Tinkercad simulation and physical hardware using a 4x4 matrix keypad, servo lock actuator, and status LEDs. Typing the correct 4-digit passcode rotates the servo to unlock the door.

PROJECT 09

LCD Code

  • I2C LCD
  • 16x2 Display
  • Arduino / ESP32

A 16x2 I2C Liquid Crystal Display (LCD) project that initializes the backlight and prints custom robotics text, live system counters, and status messages across both rows of the screen.
